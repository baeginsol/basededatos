2. Descripción del proyecto

El proyecto consiste en el diseño de una base de datos para un hotel VIP de cinco estrellas, con el objetivo de organizar y administrar la información de huéspedes, empleados, habitaciones, reservas, servicios, facturas y pagos.

Se busca desarrollar una estructura de base de datos organizada, que permita almacenar la información de manera adecuada y facilite su consulta y administración.

3. Objetivo

Diseñar e implementar una base de datos que permita gestionar la información y las operaciones principales de un hotel VIP de cinco estrellas, aplicando los conocimientos adquiridos en la materia de Bases de Datos.
